1. Тип задачи (type::) — Цвет: Синий / Фиолетовый

- type::bug — Ошибка, которую нужно исправить.

- type::feature — Новая функциональность, улучшение.

- type::tech-debt — Технический долг, рефакторинг, тесты.

- type::research — Исследование, анализ, дизайн (Spike).

2. Приоритет (priority::) — Цвет: От Зеленого до Красного

- priority::low (Зеленый) — Можно сделать, когда будет время.

- priority::medium (Желтый) — Стандартная задача в бэклоге.

- priority::high (Оранжевый) — Важная задача для текущего спринта.

- priority::critical (Красный) — Блокер, чинить прямо сейчас (Hotfix).

3. Статус для колонок на Issue Board (status::) — Цвет: Серый / Голубой

- status::backlog — Идеи и задачи на будущее.

- status::to-do — Задачи, отобранные на ближайшее время / спринт.

- status::in-progress — Задача сейчас в работе у разработчика.

- status::code-review — Код написан, ждет проверки (Merge Request).

- status::testing — Фича проверяется тестировщиком (QA).
